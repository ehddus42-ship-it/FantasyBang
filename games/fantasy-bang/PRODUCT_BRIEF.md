# PRODUCT BRIEF — 룬 크라운: 그림자 맹세

> 확정 근거: 사용자 요청(판타지 스타일, BANG! 계열의 역할 추리 포함 카드전, 웹/GitHub Pages, Firebase 제외, Meshy 만화풍 서브컬처 이미지, 영웅 수 확대)과 2026-08-11 승인. 저장소 이름 `FantasyBang`은 유지하지만 게임 표시는 오리지널 제목을 쓴다.

## 12개 제품 차원

1. **플랫폼·형태·성능 예산** — GitHub Pages에서 실행되는 반응형 웹. 마우스·터치·키보드 입력. 데스크톱 목표 1440×900, 최소 1024×700, 모바일 최소 390×844 세로 및 가로 지원. 창 모드 브라우저. 첫 상호작용 가능 2.5초 이내(일반 광대역), 전체 배포 파일 20MB 이내, 전환/이펙트 60fps 목표.
2. **목표 시장·인터페이스 언어** — 한국의 라이트~중도 전략/서브컬처 이용자. 첫 인터페이스 언어 한국어. 다국어는 이번 범위 아님.
3. **장르·대조군·공간 형태** — 비밀 역할 기반 턴제 카드 배틀. 동일 플레이 선례는 `BANG!`과 `Samurai Sword`. 공유 동사는 카드 2장 뽑기, 장비하기, 원형 좌석 거리로 대상 선택하기, 공격/방어하기, 행동을 보고 비밀 진영 추론하기. 순환 구조는 「뽑기 → 장비·공격·교란 → 반응 → 체력만큼 손패 정리 → 다음 좌석」. 공간 형태는 **2D 인터페이스**로 확정한다. 카드 선택과 원형 좌석 거리 계산이 핵심이라 캐릭터 이동이나 카메라 조작이 필요하지 않기 때문이다.
4. **아트 스타일** — Meshy AI `nano-banana-2`를 이용한 세련된 만화풍 서브컬처 판타지. 10종 영웅 초상과 메인 배경. 청금색·자주색·금색을 중심으로 한 마법 궁정, 선명한 실루엣, 카드 축소에서도 알아보이는 색 구분.
5. **콘텐츠 등급·NSFW** — 12세 이상. 비현실적 마법 전투와 가벼운 피격 연출. 유혈·신체 훼손·성적 표현·NSFW 없음.
6. **핵심 판타지·감정** — 플레이어는 비밀 맹세를 숨긴 마도 영웅이 되어, 누구를 돕고 누구를 공격할지 매 턴 연기하다가 마지막 한 장으로 왕관의 운명을 뒤집는 짜릿함을 느낀다.
7. **단판 시간·구조** — 현재 슬라이스는 인간 1명+AI 3명의 4인 단판, 목표 10~20분. 재시작 가능한 완결형 한 판. 장기 육성·일상 루프 없음.
8. **발행·상업화** — 무료 비상업 프로토타입. 결제·광고·가챠·스태미나 없음.
9. **생산 엔진·인도 런타임** — 바닐라 HTML/CSS/JavaScript 정적 앱. 목표 인도 런타임은 최신 Chromium/Safari 계열 브라우저와 GitHub Pages. Node.js는 순수 로직 코어의 자동 플레이 검증에만 사용하며 대체 인도 런타임이 아니다.
10. **플레이어·소셜 구조** — 이번 인도물은 싱글 플레이어 대 AI 3인으로 즉시 플레이된다. 4인 규칙은 공개 `왕관수호자`, 비밀 `균열단` 2명, 비밀 `최후성` 1명. 다음 단계의 Firebase 4~7인 실시간 플레이어 대 플레이어가 필수 확장 범위이며, `성약기사`는 5~7인 구성에 사용한다. 이번에는 계정·온라인 방·클라우드 세이브·랭킹·채팅과 실제 네트워크 연결만 제외한다. 게임 코어는 좌석마다 사람/AI를 교체할 수 있어야 하고, 공개 상태와 좌석별 비밀 상태, 행동 권한, 결정적 이벤트, 재동기화 스냅샷, 전송 어댑터를 분리해 Firebase가 규칙을 다시 구현하지 않도록 한다.
11. **수용자·교육 강도** — 라이트~중도 전략, 역할극·역전·서브컬처 영웅 수집을 좋아하는 이용자. 첫 1분에는 오프닝 카드, 자신의 비밀 역할 공개, 승리 조건 고정 패널, 첫 턴 3단계 하이라이트로 「나는 누구 / 무엇을 원함 / 무엇이 판을 끝냄」을 전달한다.
12. **소재 출처·권리** — 완전 오리지널 세계·영웅·명칭·문안·이미지. `BANG!`과 `Samurai Sword`는 성숙한 플레이 구조의 참고작일 뿐이며 원작 고유명, 카드명, 캐릭터, 문구, 도상, 레이아웃, 공식 자산을 사용하지 않는다. dV Games가 허가 없는 전자판 제안을 거절한다고 밝힌 점을 반영해 직접 전자 복제는 명시적 비목표다.

## 명시적 비목표

- 새 핵심 메커니즘 발명
- BANG!의 직접 전자 복제 또는 공식 호환품 표방
- Firebase 실제 연결, 로그인, 온라인 방·매치메이킹
- 이번 인도물에서의 5~7인 실제 네트워크 플레이와 성약기사 실전 배치. 단, 이를 위한 좌석·비밀정보·행동 이벤트 계약은 필수다.
- 결제, 광고, 수집형 성장, 영구 세이브
- 장기 밸런스와 상업성의 확정

## 컴플라이언스 주의

- 모든 Meshy 생성 프롬프트는 오리지널 캐릭터만 지시하고 특정 작가·작품·캐릭터를 모사하지 않는다.
- 저장소 이름은 기술 식별자일 뿐, 게임 화면·메타데이터·홍보 제목에는 `BANG!` 상표를 쓰지 않는다.
- AI 생성물의 상업 이용 조건은 실제 상업화 전에 Meshy 계정 플랜과 최신 약관을 다시 확인한다.

## 미확인 가정

- 없음. 사용자는 제작안에 대해 Meshy 크레딧 전부 사용을 승인했고, 역할 추리를 포함하도록 정정했으며, 영웅 수 확대만 요구했다. 영웅 수는 10종으로 확정한다.
